# 數學解惑（原型）

高中數學題目的教學 AI。學生輸入一題，系統用「四階段 + 圖解」帶著理解，並存進錯題本。
**重點是教思考，不是直接給答案。**

- 純前端 PWA，手機優先，部署在 GitHub Pages，可加到主畫面離線使用
- **零費用、不連任何 AI 服務、不需要金鑰**：由自己寫的解題引擎計算，結果精確、不會亂猜
- 資料只存在你自己的瀏覽器，沒有後端

> 目前進度：11 種題型、通用解法、老師模式（反問、診斷、追問）、選用的本機 AI 已可使用；圖解、錯題本開發中。

## 支援的題型

解題分三層，盡量不讓學生遇到「系統不會」就卡住：

1. **題型模板**（講解最完整，像老師上課）

   | 單元 | 題型 |
   |---|---|
   | 二次函數 | 求最大值或最小值、頂點與對稱軸、限定範圍的最值、根與交點與判別式 |
   | 二次不等式 | 解二次不等式、恆成立求參數範圍 |
   | 指數 | 指數方程式、指數不等式（令 t = aˣ） |
   | 對數 | 對數方程式、對數不等式（含定義域檢查）、對數求值（運算律、換底） |

2. **通用解法**：沒有模板的單變數方程式、不等式、最值、求值都能解（例如三次方程式、分式不等式、根號方程式）。先用數值找出所有根與分界點，再還原成精確值（分數、根式、對數），並逐一代回驗算。講解是通用步驟：定義域 → 找分界點 → 逐段判斷正負。
3. **引導思考模式**：連通用解法都不行的題目（幾何、應用題、證明等），不給答案，改用四階段提問陪學生拆題，附計算工具（代值、找等於 0 的值）。這些題目會記錄在本機，可匯出，用來決定下一個要補的題型。

輸入整題文字即可，系統會自動判斷題型；判斷錯了可以自己改選。

## 老師模式

預設是「老師帶我做」，每一階段都先讓學生自己想、自己寫：

1. **審題**：選出「這題要你做什麼」，選錯會請你再讀一次題目
2. **已知**：先想想有沒有沒說出口的條件，再對答案
3. **觀念**：選出會用到的觀念，系統告訴你選對、漏選、多選了哪些
4. **推導**：每一步先問你（例如「兩個根是多少？」），你寫答案後系統用數學判斷對錯，並說明錯在哪裡：
   - 正負號弄反、端點開閉、漏解、沒檢查定義域、方向反了等，標示錯誤類型（符號、計算、漏列條件、延伸…）
   - 可以要提示，或直接看這一步
5. **答案**：寫下最後答案再對照

每一步旁邊都有 **「我不懂」**：
- 可以點常見追問：為什麼可以這樣做、這個數字怎麼來的、這個詞是什麼意思、舉個例子、我前面的觀念不熟、要注意什麼
- 也可以直接打字問，例如「−5 怎麼來的」「判別式是什麼」。系統聽不懂時會反問你想問的是哪一種
- 回答來自每個觀念的小講義（[`data/lessons.json`](data/lessons.json)）與名詞解釋（[`data/glossary.json`](data/glossary.json)），會往下講先備觀念、舉更簡單的例子

不想做題、只想看講解時，可以切到「直接看講解」。

## 本機 AI 助教（選用）

在頁面最下方可以啟用。啟用後，「我不懂」裡用任何說法打字發問，都會交給在你裝置上執行的開源模型理解並用口語回答。

- **零費用、問題不離開裝置**：使用 [WebLLM](https://github.com/mlc-ai/web-llm)（Apache-2.0）在瀏覽器裡執行 Qwen2.5 Instruct 模型（Apache-2.0）
- 第一次要下載模型檔：標準版約 1 GB、輕量版約 0.4 GB，由 WebLLM 從 Hugging Face 下載（免費），之後存在瀏覽器裡，可離線使用，也可以一鍵刪除
- 需要支援 WebGPU 的較新裝置與瀏覽器；不支援的裝置照樣能用其他所有功能
- **AI 只負責解釋，不負責數學**：所有數字都來自解題引擎；AI 回覆中出現步驟裡沒有的數字時，會顯示提醒；學生還沒看答案前，不會把答案提供給 AI

## 四階段

1. **審題**：題目要求什麼（一句話）
2. **已知**：明示條件與隱含條件
3. **觀念**：用到哪些概念（只能從 [`data/concepts.json`](data/concepts.json) 選）
4. **延伸**：一步一步推導，每一步附理由與可驗算的算式

預設只顯示階段一，按「提示」才展開下一階段，最後才顯示答案。

## 本機執行

需要 Node.js 22 以上。

```bash
npm install        # 安裝套件，同時啟用 pre-commit 金鑰掃描
npm run dev        # 開發伺服器
npm test           # 單元測試
npm run build      # 建置到 dist/
npm run scan       # 掃描所有被追蹤的檔案是否含疑似金鑰
```

## 評測

評測集放在 [`eval/`](eval/)，說明見 [`eval/README.md`](eval/README.md)。

```bash
npm run eval       # 用解題引擎作答所有評測題並評分
```

輸出：答案正確率、概念標籤命中率、JSON 合法率。CI 每次推送都會跑，正確率低於門檻就不部署。

## 部署

推上 `main` 後，GitHub Actions 會依序執行金鑰掃描、評測、測試、建置，然後部署到 GitHub Pages。
第一次使用要到儲存庫的 **Settings → Pages**，把 **Source** 設成 **GitHub Actions**。

## 隱私

- 本專案沒有後端，不連任何雲端 AI 服務，題目不會離開你的裝置
- 只有在你主動啟用本機 AI 時，才會下載模型檔（從 Hugging Face）；你的問題仍只在裝置上處理
- 錯題本、回饋表都只存在你自己的瀏覽器裡
- 匯出的檔案請存到 `exports/`，這個資料夾已被 `.gitignore` 排除，不會被提交
- **貢獻者請勿提交**任何金鑰、個人資料、使用者回饋或錯題本匯出檔

## 題庫版權聲明

- `eval/` 與所有範例題目**只收自創或改編題**
- **不收**學校考卷、補習班講義、出版社教材或任何考試的原題
- 改編題必須在題型、數字與敘述上與原題有實質差異，並在 `source` 欄位註明「改編」
- 若你發現本儲存庫中有侵權疑慮的題目，請通知我們移除

## 安全

- 程式碼中不得出現任何金鑰
- `npm install` 會設定 git hook（`.githooks/pre-commit`），提交前自動掃描暫存區，發現疑似金鑰就擋下
- CI 也會再掃描一次所有檔案
- 建議在 GitHub 儲存庫設定開啟 Secret scanning 與 Push protection（公開儲存庫免費）

## 使用的開源套件

Vite、Vitest、mathjs、Ajv、vite-plugin-pwa、WebLLM（選用）；圖解將使用 JSXGraph
