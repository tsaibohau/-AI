# 數學解惑（原型）

高中數學題目的教學 AI。學生輸入一題，系統用「四階段 + 圖解」帶著理解，並存進錯題本。
**重點是教思考，不是直接給答案。**

- 純前端 PWA，手機優先，部署在 GitHub Pages，可加到主畫面離線使用
- **零費用、不連任何 AI 服務、不需要金鑰**：由自己寫的解題引擎計算，結果精確、不會亂猜
- 資料只存在你自己的瀏覽器，沒有後端

> 目前進度：二次函數、二次不等式（6 種題型）已可使用；指數與對數、圖解、驗算、錯題本開發中。

## 支援的題型

| 單元 | 題型 | 狀態 |
|---|---|---|
| 二次函數 | 求最大值或最小值 | ✅ |
| 二次函數 | 求頂點與對稱軸 | ✅ |
| 二次函數 | 限定範圍內的最大或最小值 | ✅ |
| 二次函數 | 根、與 x 軸交點、判別式 | ✅ |
| 二次不等式 | 解二次不等式 | ✅ |
| 二次不等式 | 恆成立，求參數範圍 | ✅ |
| 指數 | 指數方程式、指數不等式 | 開發中 |
| 對數 | 對數方程式、對數不等式、對數求值 | 開發中 |

輸入整題文字即可，系統會自動判斷題型；判斷不出來時會請你自己選。
解不出的題目會直接說明原因，不會硬給答案。

## 四階段

1. **審題**：題目要求什麼（一句話）
2. **已知**：明示條件與隱含條件
3. **觀念**：用到哪些概念（只能從 [`data/concepts.json`](data/concepts.json) 選）
4. **延伸**：一步一步推導，每一步附理由與可驗算的算式

預設只顯示階段一，按「提示」才展開下一階段，最後才顯示答案。

## 本機執行

需要 Node.js 22 以上。

```bash
npm install        # 安裝套件，同時啟用 pre-commit 金鑰掃描
npm run dev        # 開發伺服器
npm test           # 單元測試
npm run build      # 建置到 dist/
npm run scan       # 掃描所有被追蹤的檔案是否含疑似金鑰
```

## 評測

評測集放在 [`eval/`](eval/)，說明見 [`eval/README.md`](eval/README.md)。

```bash
npm run eval       # 用解題引擎作答所有評測題並評分
```

輸出：答案正確率、概念標籤命中率、JSON 合法率。CI 每次推送都會跑，正確率低於門檻就不部署。

## 部署

推上 `main` 後，GitHub Actions 會依序執行金鑰掃描、評測、測試、建置，然後部署到 GitHub Pages。
第一次使用要到儲存庫的 **Settings → Pages**，把 **Source** 設成 **GitHub Actions**。

## 隱私

- 本專案沒有後端，不連任何 AI 服務，題目不會離開你的裝置
- 錯題本、回饋表都只存在你自己的瀏覽器裡
- 匯出的檔案請存到 `exports/`，這個資料夾已被 `.gitignore` 排除，不會被提交
- **貢獻者請勿提交**任何金鑰、個人資料、使用者回饋或錯題本匯出檔

## 題庫版權聲明

- `eval/` 與所有範例題目**只收自創或改編題**
- **不收**學校考卷、補習班講義、出版社教材或任何考試的原題
- 改編題必須在題型、數字與敘述上與原題有實質差異，並在 `source` 欄位註明「改編」
- 若你發現本儲存庫中有侵權疑慮的題目，請通知我們移除

## 安全

- 程式碼中不得出現任何金鑰
- `npm install` 會設定 git hook（`.githooks/pre-commit`），提交前自動掃描暫存區，發現疑似金鑰就擋下
- CI 也會再掃描一次所有檔案
- 建議在 GitHub 儲存庫設定開啟 Secret scanning 與 Push protection（公開儲存庫免費）

## 使用的開源套件

Vite、Vitest、mathjs、Ajv、vite-plugin-pwa；圖解將使用 JSXGraph
