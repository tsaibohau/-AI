# 解題思路範本

每一類題目寫一份（例如 `應用問題-利潤最大.md`）。不用寫得很正式，用你平常教學生的講法就好；
想不到的欄位可以空著。題目請用**自創或改編**的，不要放考卷原題。

---

## 題型名稱

例如：二次函數的應用問題（利潤、面積最大）

## 看到什麼字眼，就知道是這一類

例如：「售價每提高 1 元，銷量減少…」「求最大利潤」「圍成的面積最大」

## 解題步驟（照你的順序）

1. 先做什麼？（例如：設未知數，x 代表什麼、單位是什麼）
2. 再做什麼？（例如：把文字翻譯成式子）
3. …
4. 最後怎麼檢查？（例如：x 要在合理範圍內、要回答題目問的東西）

## 每一步你會怎麼問學生

例如：第 1 步問「題目裡會變的量是哪一個？」

## 學生最常錯在哪裡

例如：忘了 x 的範圍（售價不能是負的）、算出 x 就停了沒有算利潤

## 圖要畫什麼

例如：畫利潤和售價的拋物線，標出頂點；或畫出圍籬的長方形，標長和寬
