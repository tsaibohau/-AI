# 評測集

用來衡量模型解題品質，修改提示詞或換模型前後都應該跑一次。

## 版權規定（務必遵守）

- **只收自創或改編題。**
- **不收**學校考卷、補習班講義、出版社教材、任何考試的原題，也不收從這些來源只改一兩個數字的題目。
- 改編題要在題型、數字與敘述上與原題有實質差異，`source` 欄位寫「改編」；自創題寫「自創」。
- 題目內容不得含任何個人資料。

## 題目格式（`problems.json`）

| 欄位 | 說明 |
|---|---|
| `id` | 唯一代號，例如 `q006` |
| `source` | `自創` 或 `改編` |
| `text` | 題目文字 |
| `answer.type` | `number`（單一數值）、`set`（多個解）、`interval`（範圍）、`point`（座標） |
| `answer.value` | 標準答案，例如 `-5`、`{1, 2}`、`(-inf, -1) U (3, inf)`、`(2, -5)`、`無解`、`R` |
| `concepts` | 標準概念標籤，必須是 `data/concepts.json` 裡的 id |
| `needs_diagram` | 這題是否需要圖解（`true` / `false`） |

數值可以用 mathjs 語法，例如 `sqrt(2)/2`、`log(3, 2)`（以 2 為底的 log 3）。

## 執行

```bash
npm run eval                       # 用解題引擎作答並評分
npm run eval -- --only q001,q003   # 只跑部分題目
npm run eval -- --min-accuracy 0.8 # 正確率低於 80% 時回傳錯誤（CI 用）
npm run eval -- --check            # 只檢查題目格式
```

新增題目時，若題型還不支援，該題會顯示「開發中」並計為答錯；這是正常的，代表引擎還要補。

## 指標

- **可作答率**：引擎能辨識並解出的題目比例
- **JSON 合法率**：輸出通過四階段 schema 與規則檢查的比例
- **答案正確率**：答案與標準答案數學上等價的比例（例如 `-2 < x < 3` 等於 `(-2, 3)`）
- **概念標籤命中率**：標準概念中被模型選到的比例（平均）；另列「精確率」：模型選的概念有多少在標準裡
- **圖解需求一致率**：模型有沒有給圖，與 `needs_diagram` 一致的比例

JSON 不合法的題目，答案與概念都算 0 分。
